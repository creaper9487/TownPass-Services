⑤ 推播結果（每 2 秒更新）— 用這裡判斷是誰的問題

ok
後端已成功交給 Firebase。手機沒收到 → App 端（通知權限、Firebase 設定、token 是不是最新的）。
local
沒設定 Firebase，或是本機假裝置：只記錄在本機，不會到手機。要真的推，請後端設 FCM_PROJECT_ID / FCM_CREDENTIALS_FILE。
invalid_token
token 無效或過期（已自動刪除）→ App 端重新取得 token 再登記；或 App 跟後端不是同一個 Firebase 專案。
failed
Firebase 拒絕 → 後端設定（金鑰 / 專案 ID 不對、FCM API 沒開）。
retry
暫時失敗（網路 / Firebase 忙碌），後端會自動重試。
按了沒出現新紀錄
後端沒觸發推播（或這個信箱沒有登記裝置）。
